# Paper 3 — questions and sources needed

Paper 3 has 144 distinct questions, grouped here into 66 families. A family is a set of questions answered by one answer file.

**Rule:** answers will use only the sources listed against each family, and nothing else. If a needed section is missing from a source, the answer will say so, and you will be asked for it.

## Legend

| Column | Meaning |
| --- | --- |
| **Have** | Source already uploaded: Maudsley 15e (**M**, prescribing only), DSM-5-TR (**D**, criteria only), IPS TMS CPG (**T**), breaking-bad-news notes (**B**) |
| **Need** | What to upload. Any one good source per line is enough; the first option is preferred |

- **UTD** = the UpToDate topic named.

✅ = already answered. ⚠️ = answered, but not from a source.
